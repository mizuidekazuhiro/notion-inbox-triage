# Notion Calendar：日曜始まり・4週間

既存のNotion Week / Notion Focusと同じ配色と認証を使う、大サイズ専用のScriptableウィジェット。
今週の日曜から4週目の土曜までを7列×4行で表示する。予定名を表示し、タスクのDue Dateは取得しない。

## 導入

1. この変更を含むWorkerを既存のCloudflare環境へデプロイする。
   既存と同じ NOTION_TOKEN / TASKS_DB_ID / SHORTCUT_TOKEN を利用する。追加の環境変数は不要。
2. Scriptableで新しいスクリプト「Notion Calendar」を作り、
   scripts/NotionCalendarFourWeeks.js の全文を貼り付けて保存する。
   既存のNotion Week / Focusを置き換える必要はない。
3. Scriptable内で一度実行する。Notion Weekの認証がKeychainに保存されていれば入力不要。
   未設定の場合だけ既存のX-Shortcut-Tokenを入力する。Notion APIキーは入力しない。
4. iPhoneホーム画面でScriptableの大サイズウィジェットを追加し、
   Scriptに「Notion Calendar」を指定する。Parameterは空欄。
5. 今日の日付のシアンの丸・マスの背景と枠、予定、Notionへのリンクを実機で確認する。

## 表示

- 深いネイビーのグラデーション、淡いガラス調の各日枠、シアンのアクセント。
  ホーム画面そのものを透過する機能ではなく、既存と同じガラス調の表現。
- 今日の日付はシアンの丸、マスは薄いシアンと強い枠。過去の日は文字を暗くする。
- 日曜始まり。毎週日曜の日本時間0時を境に、次回描画時に範囲を1週進める。
- 毎月1日は「11/1」形式。ヘッダーは全表示期間と今日の日付。
- 各日に最大2予定。3件以上は先頭1件と「＋残り件数」。
- 終日→時刻順。予定名は1行、省略はScriptableの描画に任せる。
- 予定名をタップすると該当Notionページへ。「＋件数」や余白は既存Notionトップを開く。
- Event Dateがある予定だけを取得。Doneも予定として表示し、Drop / archived / in_trashは除外。
- 終日終了日はNotionの最終日を含む。時刻付き終了はその瞬間を含まない。
  期間予定は重なる各日に表示する。

## APIとキャッシュ

GET /api/widget/schedule/calendar
認証ヘッダー：既存の X-Shortcut-Token。レスポンスは no-store。
JST固定の28日間。countとitemsは全件一致し、20件で切らない。
長期間の予定を落とさないため開始日の下限を設定せず、終了範囲より前に始まる予定をページング取得後、
期間の重なりを判定する。現行の上限20ページを超えた場合は502となり、不完全な予定表を成功扱いしない。
履歴が増えてこの上限や応答時間に達した場合は、予定取得方式の再検討が必要。

取得成功時に端末内ファイルへ保存。通信失敗時のみ同じ表示期間の前回データを表示し、
取得日時と「更新できません」を明記する。週をまたいだ古い範囲は再利用しない。
401や認証未設定時にはキャッシュを表示しない。初回失敗時は空のグリッドとエラーを表示する。
空配列の正常取得は、削除済み予定を残さないよう前回キャッシュを更新する。
更新は30分後を要求するが、実際の再描画はiOSが決定するため即時更新は保証しない。

## 検証と適用状況

Nodeの模擬Scriptable環境で28枠、今日の強調、予定リンク、期間境界、キャッシュを検証する。
APIでは認証、ページング、長期間予定、20件超、日本時間・月末・年末・うるう年を検証する。
iPhone / Scriptable実機での最終レイアウトと、デプロイ後のNotion実データ取得は別途確認が必要。
この変更の作成時点では本番デプロイ・iPhoneへのインストールは実施していない。

元のNotionWeekSchedule.jsとNotionFocusLarge.jsは維持。
戻す場合はホーム画面のScriptを元のNotion Weekへ変更する。
